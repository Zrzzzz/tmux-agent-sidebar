Where the state comes from

    

      

        

          Hooks inherit the agent's environment, so TMUX_PANE tells
          the collector which pane an event belongs to. That one fact is what
          makes the whole thing possible — without it an event has no address.
        

        

          Each event is a patch. Keys it doesn't set keep their previous value,
          so a tool call never erases the prompt, and the status line never
          overwrites a status only the hooks can know.

Why not read the screen

    

      The obvious approach is to grep the pane for a spinner line. It doesn't
      work: that line stays on screen after the task ends, so
      every session that ever did anything reads as busy forever. These two are
      the same session, seconds apart:
    

    

      
running   ✽ Honking… (6m 25s · ↑ 21.1k tokens · thought for 3s)

      
finished  ✻ Cogitated for 32s

    

    

      Earlier versions told them apart by the shape of the string — a live
      spinner carries parenthesised stats, a finished one doesn't. It worked,
      and it would break the day a TUI changed its layout. Hooks remove the
      guesswork: Stop fires when the turn ends, and nothing has to
      be inferred from pixels.
    

  


  

    
Install

    
# the sidebar and its collector
curl -o ~/.local/bin/tmux-agent-sidebar.sh \
  https://raw.githubusercontent.com/Zrzzzz/tmux-agent-sidebar/main/tmux-agent-sidebar.sh
curl -o ~/.local/bin/tmux-agent-sidebar-collect.sh \
  https://raw.githubusercontent.com/Zrzzzz/tmux-agent-sidebar/main/tmux-agent-sidebar-collect.sh
chmod +x ~/.local/bin/tmux-agent-sidebar*.sh

# register the hooks (merges into existing config, backs it up first)
./install-hooks.sh claude
./install-hooks.sh codex     # restart Codex afterwards

    

      Then bind it: bind a run-shell '~/.local/bin/tmux-agent-sidebar.sh
      --toggle #{pane_id}'. Passing #{pane_id} is not
      optional — run-shell doesn't export TMUX_PANE,
      and without a target tmux falls back to the currently active window,
      which may not be the one you pressed the key in.
